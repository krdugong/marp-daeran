마이프로틴(Myprotein) 맛에 대해 사람들이 쓴 글을 읽고 정리하는 조사 작업입니다. 글을 쓰거나 댓글을 달거나 로그인하지 말고, 읽기만 하세요. 보안 확인 화면(캡차, 'I am human', Access Denied)이 나오면 우회하지 말고 그 사이트는 건너뛰세요. 같은 사이트에 빠르게 연속 요청하지 마세요.

## 1. 검색어 8개
네이버 자동완성에 뜨는 아래 8개 검색어를 하나씩 네이버(통합검색의 블로그·카페·VIEW 탭)와 유튜브, 디시인사이드(헬스 갤러리·보충제 갤러리)에서 검색하세요.
1. 마이프로틴 맛 종류
2. 마이프로틴 맛 순위
3. 마이프로틴 맛 추천
4. 마이프로틴 맛 추천 디시
5. 마이프로틴 맛 비교
6. 마이프로틴 맛 리뷰
7. 마이프로틴 맛 후기
8. 마이프로틴 맛 추천 wpi

검색어마다 검색 결과 상단의 글 중 2025년 이후 글을 우선해 5~8개를 실제로 열어 읽으세요(전체 40~60개). 광고·협찬 글(제휴 링크, '협찬'·'원고료' 표시)은 빼고, 같은 블로그의 글은 검색어당 1개만 읽으세요. 각 검색어의 네이버 연관검색어와 자동완성도 같이 적어 두세요.

## 3. 다 읽은 뒤 맛별로 합치기
읽은 글 전체를 바탕으로 맛마다:
```json
{
  "name": "맛 이름",
  "product": "임팩트웨이 | 아이솔레이트 | 클리어웨이",
  "mentions": 글에서 언급된 횟수(숫자),
  "good": 추천 횟수, "bad": 비추 횟수,
  "score": 1~5점 소수 한 자리 (추천 비율 기준, 언급 3회 미만이면 null),
  "mix": "물 | 우유 | 둘 다 | 모름",
  "beginner": 처음 사는 사람에게 권하는 글이 많으면 true,
  "summary": "20~40자 총평",
  "pros": ["장점 짧게"], "cons": ["단점 짧게"],
  "quotes": [ { "source": "출처 종류", "url": "글 주소", "date": "YYYY-MM-DD 또는 null", "text": "20~40자 요약" } ]
}
```

## 4. 자주 묻는 질문
읽은 글과 연관검색어를 바탕으로, 사람들이 실제로 묻는 꼴의 질문 8~12개를 만들고 글 내용을 근거로 2~3문장으로 답하세요. 답에는 맛 이름을 구체적으로 넣으세요.
```json
{ "q": "마이프로틴 무맛은 어때요?", "a": "...", "kw": "근거가 된 검색어" }
```

## 5. 저장
현재 작업 폴더(명령을 실행한 폴더)에 `result.json` 파일로 저장하세요. 다른 폴더에는 아무것도 쓰지 마세요. 형식:
```json
{
  "checked": "YYYY-MM-DD",
  "keywords": [ { "kw": "검색어", "related": ["네이버 연관검색어·자동완성"], "read": 읽은 글 수 } ],
  "posts": [ ...2번... ],
  "flavors": [ ...3번... ],
  "faq": [ ...4번... ],
  "notes": "막힌 사이트, 못 읽은 것, 주의할 점"
}
```
값을 못 찾으면 지어내지 말고 null 로 두세요. 저장한 뒤 파일을 다시 열어 JSON이 올바른지 확인하세요.
