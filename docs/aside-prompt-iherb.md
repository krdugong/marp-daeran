아이허브 한국 사이트(kr.iherb.com)에서 오메가3, 마그네슘, 유산균 제품의 함량·가격·평점과 후기를 모아서 JSON 하나로 정리해 줘. 사이트(proteify.kr)의 아이허브 추천 페이지에 "하루치 가격 비교표"와 "후기 요약"으로 넣을 데이터야. 아이허브 블프 기록, 지금 쓸 수 있는 할인코드, 네이버 연관검색어도 같이 모아 줘.

## 1. 제품 (카테고리마다 8~10개)
- 카테고리: 오메가3(피쉬오일), 마그네슘, 유산균(프로바이오틱스)
- 고르는 법: kr.iherb.com에서 카테고리를 검색해서 베스트셀러·리뷰 많은 순으로 상위 제품. 같은 제품의 용량만 다른 건 가장 많이 팔리는 용량 1개만.
- 아래 4개는 이미 페이지에 있으니 꼭 포함해 줘:
  - 캘리포니아 골드 뉴트리션 오메가 800 (30정), 캘리포니아 골드 뉴트리션 오메가3 프리미엄 피쉬 오일 (100정), 스포츠리서치 트리플 스트렝스 오메가3 (180정), 스포츠리서치 알래스칸 오메가3 (90정)
- 제품마다 상세페이지의 "영양 성분 정보(Supplement Facts)" 표와 상품 정보에서 읽는다:
  - name: 아이허브 한국 페이지에 보이는 한글 제품명 그대로
  - brand, url(상세페이지 주소), kw(영문 제품명, 아이허브 검색어로 쓸 것)
  - count: 한 통에 든 정·캡슐 수
  - perServing: 1회 섭취량이 몇 정인지
  - price: 오늘 1회 구매가(원). 세일가가 보이면 세일가. 정기배송가는 autoship에 따로.
  - rating(별점), reviews(리뷰 수), inStock
  - 카테고리별 함량 (1회 섭취량 기준):
    - 오메가3: epa(mg), dha(mg), form(rTG / TG / EE / 표기 없음), cert(IFOS 등 제3자 인증 표기, 없으면 null), capsule(생선 젤라틴 / 소 젤라틴 / 식물성 등)
    - 마그네슘: elemental(원소 마그네슘 mg), form(글리시네이트 / 시트레이트 / 옥사이드 / 말산염 / 혼합 등), type(정제 / 캡슐 / 분말)
    - 유산균: cfu(억 단위 숫자, 예: 500억이면 500), guarantee("유통기한까지" / "제조 시" / 표기 없음), strains(균주 수), storage(실온 / 냉장), lgg(락토바실러스 람노서스 GG 들어 있으면 true)
  - note: 특이사항(예: "1회 2정 기준이라 크게 보임", "품절 잦음")
- 효능을 단정하는 말은 쓰지 마. 라벨과 제품명에 적힌 사실만.

## 2. 후기 (카테고리마다 6~10개)
- 출처: 아이허브 제품 페이지의 한국어 리뷰, 디시(영양제·헬스 관련 갤러리), 네이버 카페·블로그.
- 위 1번에서 고른 제품에 대한 후기를 우선.
- 협찬·광고 글("제공받아", "소정의 원고료" 등)은 빼. 마프대란알리미 채널 글도 빼.
- quote: 60자 이내 요약. 닉네임 등 개인정보는 빼.
- sentiment: 긍정/부정/중립. topic: 효과체감/목넘김/비린내/소화/가격/배송/유통기한 중 하나.

## 3. 아이허브 블랙프라이데이 기록
- 2022~2025년 아이허브 블프·사이버먼데이 행사 날짜, 할인 내용(전체 코드·할인율·자체 브랜드 세일 등), 출처 주소.
- 2026년 블프 일정이 아이허브에 공지돼 있으면 그 내용과 주소.

## 4. 지금 쓸 수 있는 아이허브 할인코드
- kr.iherb.com 메인 배너, 프로모션(특가) 페이지에 보이는 코드만.
- code, label(무엇에 몇 %), rate, who(전체 / 신규 / 대상 제품만), until(끝나는 날, 안 적혀 있으면 null), url(본 페이지).
- 블로그에 떠도는 코드는 넣지 마. 아이허브 사이트에서 직접 보이는 것만.

## 5. 네이버 연관검색어
- 네이버 검색창에 아래를 하나씩 쳐서 자동완성과 연관검색어를 전부 적어 줘:
  "아이허브 추천", "아이허브 영양제 추천", "아이허브 오메가3", "아이허브 마그네슘", "아이허브 유산균", "아이허브 블프", "아이허브 비타민", "아이허브 직구"
- 자동완성에 나오는 영양제 이름(예: 비타민D, 밀크씨슬, 루테인)은 따로 모아서 많이 나온 순으로.

## 하지 말 것
- 로그인, 회원가입, 장바구니 담기, 결제, 쿠폰 받기 금지. 보이는 정보만 읽어.
- 모르는 값은 추측하지 말고 null로 두고 note에 이유.
