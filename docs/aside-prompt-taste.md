# 어사이드용 프롬프트 — 마이프로틴 맛 추천 (복사해서 붙여넣기)

아래 세 가지 일을 해 주세요. 결과는 **JSON만** 돌려주세요(설명 글 없이). 한국어로 적고, 수치는 숫자로만 적어 주세요. 못 찾은 값은 지어내지 말고 null 로 두고 note 에 이유를 적어 주세요. 로그인, 봇 확인(캡차) 우회, 같은 사이트에 빠른 연속 요청은 하지 마세요.

## 1. 네이버 연관검색어·자동완성 전부 모으기

기준 검색어: **마이프로틴 맛추천**

- 네이버 검색창 자동완성(검색어를 치면 아래에 뜨는 것)과 검색 결과 하단 "연관 검색어"를 전부 적어 주세요.
- 그 연관 검색어 각각을 다시 검색해서 나오는 자동완성·연관 검색어도 한 단계 더 모아 주세요(2단계까지).
- 아래 씨앗 검색어도 같은 방법으로 돌려 주세요: `마이프로틴 맛 순위`, `마이프로틴 맛 종류`, `마이프로틴 맛 후기`, `마이프로틴 클리어웨이 맛 추천`, `마이프로틴 아이솔레이트 맛 추천`, `임팩트웨이 맛 추천`, `마이프로틴 무맛`, `마이프로틴 맛 디시`
- 중복은 합치고, 가능하면 네이버 광고 키워드도구(또는 블랙키위 같은 무료 조회 사이트)에서 **월간 검색수(PC+모바일 합계)** 를 붙여 주세요. 못 보면 null.

각 검색어는 이 형식으로:
```json
{ "kw": "마이프로틴 맛 추천 2026", "volume": 1200, "from": "자동완성 | 연관검색어", "seed": "마이프로틴 맛추천", "intent": "추천 | 순위 | 종류 | 후기 | 특정맛 | 제품군 | 기타" }
```

## 2. 맛별 커뮤니티 평가 모으기

마이프로틴 한국 사이트(kr.myprotein.com 또는 www.myprotein.co.kr)에서 지금 파는 **임팩트웨이, 아이솔레이트, 클리어웨이** 맛 전부에 대해, 2025년 이후 글 위주로 맛마다 후기 5~15건을 모아 요약해 주세요.

출처: 디시인사이드(헬스 갤러리·보충제 갤러리), 네이버 카페(헬스·보충제 카페), 네이버 블로그 후기, 유튜브 리뷰 영상 댓글, 마이프로틴 사이트 상품 리뷰.

맛마다 이 형식으로:
```json
{
  "flavor": "말차라떼",
  "product": "임팩트웨이 | 아이솔레이트 | 클리어웨이",
  "score": 4.5,
  "mentions": 23,
  "good": 18,
  "bad": 3,
  "summary": "20~40자 한 줄 총평",
  "pros": ["달지 않다", "우유에 타면 진짜 말차라떼"],
  "cons": ["물에 타면 밍밍"],
  "mix": "물 | 우유 | 둘 다 | 모름",
  "beginner": true,
  "quotes": [
    { "source": "디시 헬스갤 | 네이버 카페 | 네이버 블로그 | 유튜브 댓글 | 마이프로틴 리뷰", "url": "원문 주소", "date": "YYYY-MM-DD 또는 null", "text": "20~40자 요약 (닉네임·개인정보 빼고, 원문 길게 복사하지 말 것)" }
  ],
  "note": null
}
```
규칙:
- score 는 긍정/부정 비율로 1~5점(소수 한 자리). 후기가 3건 미만이면 score 는 null.
- beginner 는 "처음 사는 사람에게 권할 만한가"입니다. 후기에서 "입문용", "실패 없음", "무난" 같은 말이 많으면 true.
- 광고·협찬 글(제휴 링크, '협찬' 표시)은 빼 주세요. 같은 사람이 여러 번 쓴 글은 한 건만.
- 같은 맛이 제품군마다 있으면(예: 초콜렛 브라우니 임팩트웨이 / 아이솔레이트) 따로 적어 주세요.
- 단종됐거나 지금 안 파는 맛은 "discontinued": true 를 붙여 주세요.

## 3. 자주 묻는 질문 만들기

1번 검색어 중 사람들이 묻는 꼴인 것(예: "마이프로틴 무맛 어때요", "클리어웨이 맛 추천", "마이프로틴 우유에 타면")을 골라 8~12개 질문을 만들고, 2번에서 모은 후기를 근거로 2~3문장으로 답해 주세요. 답에는 맛 이름을 구체적으로 넣어 주세요.

```json
{ "q": "마이프로틴 무맛은 어때요?", "a": "...", "kw": "마이프로틴 무맛" }
```
